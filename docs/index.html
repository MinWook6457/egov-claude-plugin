eGov Claude

전자정부 표준프레임워크 개발환경(eGovFrameDev)에서 Claude Code 를 쓰는 플러그인의 업데이트 사이트입니다.

  1. eGovFrameDev 에서 Help > Install New Software...
  2. Add... 를 누르고 Location 에 https://minwook6457.github.io/egov-claude-plugin/update-site/ 입력
  3. eGov Claude 체크 → Next → 라이선스 동의 → Finish → Install anyway → 재시작

자세한 사용법: github.com/MinWook6457/egov-claude-plugin
